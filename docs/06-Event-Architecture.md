# 06 - Event Architecture

## Purpose

This document defines how events are generated, processed, analyzed, and stored within Sentinel Platform.

The Event Architecture is the communication layer between the Workspace and the AI Engine.

---

# What is an Event?

An Event is a record of a meaningful user action performed inside the platform.

Every important user interaction generates exactly one Event.

Examples:

- User Login
- User Logout
- Project Created
- Task Updated
- File Uploaded
- File Downloaded
- Note Created
- Message Sent
- Password Changed

---

# Event Lifecycle

Every Event follows the same lifecycle.

User

↓

Workspace

↓

Event Generated

↓

Event Pipeline

↓

↓

↓

↓

Security Dashboard

---

# Event Generation

Business modules generate Events automatically.

Examples:

| Module         | Event |
|---------       |-------|
| Authentication | User Login |
| Projects       | Project Created |
| Tasks          | Task Completed |
| File Management| File Uploaded |
| Notes          | Note Created |
| Team Chat      | Message Sent |

---

# Event Pipeline

## Purpose

The Event Pipeline collects every Event generated by the system.

Its responsibilities are:

- Receive Events
- Validate Events
- Add Timestamp
- Forward Events to the AI Engine
- Store Events

The Event Pipeline does not make security decisions.

---

# AI Analysis

After an Event reaches the AI Engine, the system performs:

- Behavioral Analysis
- Anomaly Detection
- Risk Score Calculation
- Threat Evaluation
- Explanation Generation

---

# Event Storage

Every processed Event is stored for:

- Security investigations
- Historical analysis
- AI training
- Reporting
- Auditing

---

# Security Dashboard

The Security Dashboard displays:

- Live Events
- Risk Scores
- AI Alerts
- High-Risk Users
- Investigation Timeline

All displayed information originates from processed Events.

---

# Core Principles

Every meaningful action creates one Event.

Every Event passes through the Event Pipeline.

Every Event is analyzed by the AI Engine.

Every analyzed Event is stored.

The Security Dashboard displays analyzed Events only.

---

# Benefits

The Event Architecture provides:

- Real-time monitoring
- Centralized event collection
- Consistent AI analysis
- Historical tracking
- Explainable security decisions
